# Overnight Gemma Chat Agent

A local agent that reads your WhatsApp group chats overnight and gives you a two-line summary every morning. Summaries are generated by a Gemma model running on your own machine, so your messages never leave it.

## How it works

1. Connect WhatsApp by scanning a QR code.
2. Choose the groups to watch and the time you want the digest.
3. Overnight, the agent saves the group messages locally.
4. At the set time, a local Gemma model writes two lines per group: a summary and any action items.
5. The digest is sent to your WhatsApp Self-DM.

## Tech stack

- **Frontend:** React 19, Vite, plain CSS (responsive from phones to large monitors)
- **Backend:** Node.js, Express 5, Baileys (WhatsApp), SQLite, node-cron
- **Model:** Gemma 2 2B (`gemma2:2b`) served by Ollama

## Project structure

```
overnight-gemma-agent/
├── backend/    API server, WhatsApp connection, summarizer, database
└── frontend/   React dashboard
```

## Quick start

You need Node.js 20+ and [Ollama](https://ollama.com).

```bash
# 1. Model
ollama pull gemma2:2b
ollama serve

# 2. Backend (port 4000)
cd backend
npm install
node server.js

# 3. Frontend (open the URL Vite prints, usually http://localhost:5173)
cd frontend
npm install
npm run dev
```

## Privacy

Everything runs on your machine. Chat messages are stored in a local SQLite file, and logout permanently deletes them along with the WhatsApp session. The only outside connection is WhatsApp itself.

## Known limitations

- WhatsApp is accessed through Baileys, an unofficial library. WhatsApp can change its protocol and break the connection.
- One WhatsApp session is supported at a time.
- The API has no login, so run it only on a machine you control.
